1파일 올리기

일러스트(.ai), 포토샵(.psd), 피그마에서 내보낸 PDF(.pdf), 이미지(.jpg/.png)를 올릴 수 있어요. 파일은 이 컴퓨터 안에서만 처리되고 어디에도 전송되지 않아요.

여기에 파일을 끌어다 놓거나 클릭하세요.ai · .psd · .pdf · .jpg · .png
파일 준비 요령 (처음이면 꼭 읽어 주세요)
  • 일러스트: 저장할 때 "PDF 호환 파일 만들기"를 켜 두세요(기본값). 글자는 윤곽선 만들기(아웃라인) 하지 마세요 — 아웃라인한 글자는 사진으로 들어가요.
  • 포토샵: 글자는 텍스트 레이어로 남겨 두세요. 그림자·테두리 같은 레이어 효과와 조정 레이어는 반영되지 않으니, 사진 쪽은 미리 합쳐(래스터화) 주세요.
  • 피그마: 상세페이지 프레임을 선택 → Export → PDF로 내보내서 올려 주세요. 글자를 Outline 처리하지 마세요.
  • 폰트는 Pretendard를 쓰면 손님 화면에서도 똑같이 보여요. 다른 폰트는 비슷한 기본 폰트로 바뀌어 보여요.
  • 아트보드는 같은 가로폭(예: 860)으로 맞춰 주세요. 폭이 다른 아트보드는 자동으로 빠져요(직접 선택 가능).

2설정 확인

상세페이지에 넣을 아트보드를 고르세요. 클릭하면 선택/해제돼요. 위에서부터 순서대로 이어 붙여요.

4사진 올리고 코드 받기

손님 화면에 사진이 보이려면 사진이 카페24 서버에 올라가 있어야 해요. 아래 순서대로 해 주세요.

  1. 사진·코드 저장하기 저장할 곳(예: 바탕화면)을 고르면 그 안에 _상세페이지 폴더가 생기고, 카페24에 올릴 사진 폴더와 코드가 같이 저장돼요.
  2. 카페24에 사진 올리기
    카페24 관리자 → 디자인 → 파일 업로더 → detail 폴더 안에 아래 이름으로 새 폴더를 만들고, 사진을 전부 끌어다 놓으세요. 상품 에디터의 사진 버튼으로 올리면 파일 이름이 바뀌어서 안 돼요.
    은(는) 카페24 쇼핑몰이 아니라서 사진 올리는 곳이 달라요. 사진을 손님이 볼 수 있는 곳(쇼핑몰 서버 등)에 아래 이름의 폴더로 올리고, 그 폴더 주소를 3번 "사진 폴더 주소"에 넣어 주세요.
    다시 변환했다면 사진을 전부 다시 올리고 코드도 새로 복사해 주세요. "같은 이름의 파일이 있다"고 나오면 건너뛰어도 괜찮아요 (내용이 같은 사진이에요).
  3. 사진 주소 확인
  4. 코드 복사해서 붙여넣기
    카페24: 상품 상세설명 → HTML 모드에 붙여넣기
